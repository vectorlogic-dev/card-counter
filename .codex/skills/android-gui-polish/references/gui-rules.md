## GUI Rules For This Repo

1. Keep all gameplay-critical data visible without scrolling whenever possible:
- Running count
- True count
- Deck controls and penetration
- Card input panel

2. Prefer compact composition patterns:
- Row for related metrics.
- Short labels.
- Reduced paddings in dense cards.

3. Use consistent card/button rhythm:
- Keep spacing between sections small and even.
- Keep button heights balanced for quick repeated taps.

4. Keep readability priority:
- High-contrast foreground values.
- Avoid decorative text that competes with numbers.
- Preserve clear hierarchy (title > metric > helper text).

5. Do not change counting math during UI polish unless the user requests logic changes.
